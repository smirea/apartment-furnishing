# Living room concepts — measured revision

Four independent design delegates generated these concepts using the built-in image_gen tool. Each concept.md records immutable geometry, an item dimension and coordinate schedule, numeric fit checks written before generation, final prompts and visual limitations. Open comparison.html to compare the four options.

The shared-geometry.md file establishes tape-measured spans and distinguishes them from traced or unknown positions. Important correction from the earlier concepts: the living-room television wall is 122 inches wide. A centered 85.8-inch-wide TV has 18.1-inch side margins.

These are furnishing concepts. Numeric coordinate checks establish proposed fit; image generation does not certify the rendered architecture or furniture dimensions. Exact mullions, column setback interpretation, island endpoints and door dimensions are not fully surveyed. See each design's review before relying on visible clearances.
